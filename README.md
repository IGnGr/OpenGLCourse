# OpenGL Renderer
Personal Project to learn OpenGL. 

## Features
 - 3D OpenGL renderer.
 - Supports textures and meshes.
 - Implements some basic ambient, specular and diffuse lighting.
 - Parses and renders a subset of GLTF files.

## Requirements
- Visual Studio 2022


## Usage
- Build and run with Visual Studio
